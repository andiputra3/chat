## Project Description

AI Project Manager OS is a comprehensive platform for managing AI-driven software development projects. It provides a 3-layer architecture for specification-driven development, enabling consistent project generation through automated workflows.

## Architecture Layers

### Layer 1: AI Project Manager OS
- Dashboard with 10 views
- Session management
- Git integration (via GitPython)
- Knowledge library
- Authentication (JWT)
- Notification center

### Layer 2: AI Project Factory
- Specification generation from ideas
- 22 document templates
- Cross-validation engine
- FINAL_SPEC compilation
- Build passport generation

### Layer 3: AI Project Builder
- Source code generation via AI
- Test execution
- Validation and reporting
- Git commit automation
